# Aqua Vitaeum
> Personal Scotch Whisky Collection & Interactive Tasting Ledger

## Overview
Aqua Vitaeum is an offline-first Scotch whisky personal ledger featuring a dark vintage pub aesthetic and comprehensive tasting analytics. It provides interactive printable tasting cards, dual radar charts for nose and palate profiles, and an interactive multi-level German "whic" flavor wheel for sensory exploration using local mock schemas.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Visualization**: Recharts
- **Icons**: Lucide Icons
